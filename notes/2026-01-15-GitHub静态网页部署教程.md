# GitHub静态网页部署教程

## 1. GitHub Pages简介

GitHub Pages是GitHub提供的静态网站托管服务，允许用户免费托管静态网页（HTML、CSS、JavaScript等），支持自定义域名，并且可以与GitHub仓库无缝集成。

主要特点：
- 完全免费
- 支持HTTPS
- 支持自定义域名
- 自动部署（push代码后自动更新）
- 支持Jekyll等静态网站生成器

## 2. 创建GitHub仓库

### 2.1 登录GitHub

首先登录你的GitHub账号，如果没有账号，需要先注册一个。

### 2.2 创建新仓库

1. 点击页面右上角的"+"号，选择"New repository"
2. 填写仓库信息：
   - Repository name：可以是`username.github.io`（个人站点）或自定义名称（项目站点）
   - Description：可选，填写仓库描述
   - Visibility：选择"Public"（GitHub Pages要求仓库必须是公开的）
3. 点击"Create repository"创建仓库

## 3. 准备静态网页文件

### 3.1 本地创建项目结构

```
my-personal-site/
├── index.html          # 首页
├── css/
│   └── style.css       # 样式文件
├── js/
│   └── main.js         # JavaScript文件
└── images/             # 图片目录
    └── logo.png
```

### 3.2 编写HTML文件

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Personal Site</title>
    <link rel="stylesheet" href="css/style.css">
</head>
<body>
    <header>
        <h1>Welcome to My Site</h1>
    </header>
    <main>
        <p>This is a simple static website deployed on GitHub Pages.</p>
    </main>
    <script src="js/main.js"></script>
</body>
</html>
```

## 4. 部署静态网页

### 4.1 初始化本地Git仓库

在项目根目录下执行：

```bash
git init
git add .
git commit -m "Initial commit"
```

### 4.2 连接到GitHub仓库

```bash
git remote add origin https://github.com/username/repository-name.git
```

### 4.3 推送代码到GitHub

#### 个人站点（username.github.io）

```bash
git push -u origin main  # 推送到main分支
```

#### 项目站点（自定义仓库名）

1. 创建并切换到`gh-pages`分支：
   ```bash
   git checkout -b gh-pages
   ```
2. 推送代码：
   ```bash
   git push -u origin gh-pages
   ```

## 5. 配置GitHub Pages

### 5.1 进入仓库设置

1. 进入GitHub仓库页面
2. 点击"Settings"标签
3. 在左侧菜单中选择"Pages"

### 5.2 配置部署源

在"Build and deployment"部分：
- Source：选择"Deploy from a branch"
- Branch：选择部署分支（个人站点选择main，项目站点选择gh-pages）
- Folder：选择要部署的文件夹（通常为/root）
- 点击"Save"保存设置

### 5.3 访问部署的网站

配置完成后，GitHub会显示你的网站URL，通常是：
- 个人站点：`https://username.github.io/`
- 项目站点：`https://username.github.io/repository-name/`

## 6. 自定义域名设置

### 6.1 购买域名

可以从阿里云、腾讯云、GoDaddy等域名注册商购买域名。

### 6.2 配置DNS记录

登录你的域名注册商控制台，添加以下DNS记录：

| 类型 | 主机记录 | 记录值 | TTL |
|------|---------|-------|-----|
| A    | @       | 185.199.108.153 | 600 |
| A    | @       | 185.199.109.153 | 600 |
| A    | @       | 185.199.110.153 | 600 |
| A    | @       | 185.199.111.153 | 600 |
| CNAME | www     | username.github.io | 600 |

### 6.3 在GitHub中添加自定义域名

1. 进入GitHub仓库的"Settings" → "Pages"
2. 在"Custom domain"部分输入你的域名（如`example.com`）
3. 点击"Save"
4. 勾选"Enforce HTTPS"启用HTTPS

## 7. 自动部署设置

### 7.1 使用GitHub Actions

创建`.github/workflows/deploy.yml`文件：

```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: [ main ]

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v2
    - name: Build
      run: |
        # 这里可以添加构建命令，如npm install && npm run build
    - name: Deploy
      uses: peaceiris/actions-gh-pages@v3
      with:
        github_token: ${{ secrets.GITHUB_TOKEN }}
        publish_dir: ./  # 构建输出目录
```

## 8. 常见问题与解决方案

### 8.1 网站更新不及时

- 等待一段时间，GitHub Pages可能有延迟
- 检查浏览器缓存，尝试强制刷新（Ctrl+F5）
- 检查部署分支是否正确

### 8.2 自定义域名无法访问

- 检查DNS记录是否正确配置
- 检查GitHub仓库中的自定义域名设置
- 确保域名已通过HTTPS验证

### 8.3 资源文件无法加载

- 检查资源文件路径是否正确（使用相对路径）
- 确保资源文件已被推送到GitHub仓库
- 检查文件权限是否正确

## 9. 最佳实践

1. **保持代码结构清晰**：合理组织文件目录，便于维护
2. **使用.gitignore文件**：排除不需要版本控制的文件（如node_modules、日志文件等）
3. **定期备份**：虽然GitHub提供版本控制，但建议定期备份重要文件
4. **测试不同浏览器**：确保网站在主流浏览器中都能正常显示
5. **使用响应式设计**：确保网站在不同设备上都有良好的显示效果
