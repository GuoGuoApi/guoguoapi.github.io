# 🎉 个人网站模板

## 👨‍💻 关于这个项目

你好呀！我是一个技术小白，通过AI工具的帮助，搭建了这个简单的个人网站模板~ 🚀

这个网站主要用于记录我的学习心得、分享资料和展示个人简历，是一个完全静态的网站，不需要复杂的服务器配置，非常适合像我这样的新手使用！

## ✨ 网站特点

- 📝 **学习记录**：记录学习过程中的点滴收获
- 📄 **个人简历**：简洁美观的简历展示页面
- 📚 **资料展示**：多维度的资料筛选与展示
- 📢 **最新动态**：分享生活和学习中的最新消息
- 📱 **响应式设计**：适配各种屏幕尺寸，手机也能轻松访问

## 📁 项目结构

```
my-personal-site/
├── about.html           # 个人简历页面
├── blog.html            # 学习记录列表
├── blog-detail.html     # 学习记录详情
├── css/                 # 样式文件
├── assets/              # 数据文件（简历、更新日志等）
├── notes/               # 学习记录Markdown文件
├── js/                  # JavaScript文件
├── lib/                 # 第三方库
├── password.html        # 密码验证页面
├── resources.html       # 资料展示页面
├── storage/             # 图片、文档等资源存储
├── updates.html         # 最新动态页面
└── DETAILED_TUTORIAL.md # 详细使用教程
```

## 🛠️ 如何使用

### 快速开始

1. **本地预览**：
   ```bash
   cd 项目文件夹
   python -m http.server 8000
   ```
   然后在浏览器中访问 `http://localhost:8000`

2. **内容管理**：
   - 📄 **更新简历**：编辑 `assets/resume.md` 文件
   - 📝 **添加学习记录**：在 `notes/` 目录下创建Markdown文件
   - 📢 **发布动态**：编辑 `assets/updates.md` 文件
   - 📚 **添加资料**：编辑 `assets/resources.json` 文件

### 详细教程

如果需要更详细的使用说明，请查阅项目中的 `DETAILED_TUTORIAL.md` 文件，里面包含了完整的配置和使用指南~ 📖

## 🎨 自定义设置

- **修改主题颜色**：编辑 `css/style.css` 中的CSS变量
- **调整导航菜单**：修改各个HTML文件中的导航链接
- **设置密码保护**：编辑 `password.html` 中的密码

## 🚀 部署到线上

这个网站是纯静态的，可以轻松部署到：
- GitHub Pages（可参考[DEPLOYMENT.md](DEPLOYMENT.md)实现）
- Netlify
- Vercel
- 任何静态文件服务器

## 💡 小贴士

- 所有内容都支持Markdown格式，编辑起来非常方便
- 图片等资源请放在 `storage/` 目录下
- 定期备份你的内容文件哦~ 🔒
